# Data Visualization Project Report

## 1. Project Title

Online Retail Data Visualization

## 2. Internship

CodeAlfa Data Analytics Internship

## 3. Objective

The objective of this project is to analyze online retail sales data using charts and graphs to understand sales trends and identify important business insights.

## 4. Dataset

The project uses an Online Retail dataset containing information about customer purchases, product quantities, prices, invoice dates, and countries.

## 5. Tools and Technologies

* Python
* Pandas
* Matplotlib
* VS Code

## 6. Work Performed

The dataset was analyzed using Python. The data was processed to understand sales patterns and create visualizations.

The following charts were created:

1. **Monthly Sales Chart:** Shows how sales change from month to month.
2. **Top 10 Countries Chart:** Displays the top 10 countries based on sales.

## 7. Key Insights

* The monthly sales chart helps identify changes in sales over time.
* The top 10 countries chart helps identify the countries contributing the most to sales.
* Visualizations make the sales data easier to understand.

## 8. Conclusion

This project helped me learn how to analyze retail data and present information using charts. I gained practical experience with Python, Pandas, and Matplotlib.
